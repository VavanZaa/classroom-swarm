# A24: universal previous-homework grade feedback (V4.2-G)

2026-09-24. The user clarified that "checking" means every student receives the previous homework grade, not an optional study activity. The user's subsequent typo correction is authoritative: **poor grades increase interest in cheating**, while good copied grades can feel rewarding and reinforce copying. A22/A23 checking semantics misinterpreted this intention. Their locked runs remain historical records, not evidence for the intended mechanism. This separate correction supersedes A23 as the intended working model. The initial A24 draft's attempt/question incentive was corrected before any scientific run or source lock.

## Interface and timeline

`GradeParams(V4Params)` defaults to `allow_check=False` (required), `grade_target=.75`, `grade_response=.4`. Both new parameters must be finite and in [0,1]. No optional checking action exists. `simulate_grades` is an explicit source fork of A22, retaining fixed graphs, private local information, semantic randomness, activities/time, assistance, unaided exams and original attempt/provider learning rates. Earlier locked sources remain unchanged.

Every homework produces one grade for each student, including a zero for missing work. At the start of homework h+1, EVERY student receives their grade from h, without occupying any homework ticks or changing K. No grade is known during h. The last homework is also returned at a terminal h=H+1 boundary, with no additional work or early exam-feedback delivery. End-of-homework student snapshots precede receipt of that homework's grade. Terminal feedback is recorded separately, not silently applied to those snapshots.

New private scalar `grade_shortfall` starts at 0 and is replaced after each returned grade by `max(grade_target-grade,0)`. Signed `grade_satisfaction=grade-grade_target` records the proposed good/bad reaction; it is an operational proxy, not a validated emotional scale. Satisfaction acts through the same observed grade's reinforcement and the reset shortfall, not through an additional hidden happiness bonus. Good grades clear improvement pressure. Poor grades increase it; a later good grade can recover the student. No accumulating stress, persistent personality type or withdrawal is imposed.

## Grade reinforcement and copying response

Update private action-benefit expectations at grade receipt, never at submission: `B += eta_benefit * credit * (grade-B)`. Credit reflects the student's own submitted route: an unaided final answer credits attempt=1; a copied final answer credits answer=1; a guided final attempt credits attempt=.5 and hint=.5. A missing packet receives normalized counts of attempted own activities (if any), learning from an unsuccessful episode. Successful high-grade copying therefore increases B_answer when the grade exceeds its expected benefit. A disappointing copied grade lowers B_answer when below that expectation. No automatic cheating detection or moral penalty is introduced. These directions are relative to prior expectation, not guaranteed merely by the label "good" or "bad".

Self-assessment updates from the returned grade: `C += eta_confidence * weight * (grade-C)`, with weight=1 for unaided work and inherited `misattribution=.2` for assisted work. Missing work still affects grade pressure and action expectations, but not estimated unaided competence. Exams retain A22's separately delayed assessment updates and never directly change knowledge.

The within-homework policy retains the attempt/hint/answer/wait/submit scores. Add `grade_response * grade_shortfall` only to feasible **answer requests (cheating)**. This is pressure to obtain a better grade through copying, not a direct learning increment or increased study incentive. Attempts and explanation requests receive no additional shortfall bonus. A request for explanation remains asking a question to learn; a request for an answer is expedient copying. The model does not generate natural-language questions. Reactions change probabilities, not compulsory actions: a low grade can also reduce B_answer after a failed copied answer, so reinforcement and pressure can compete.

Benefit arrays use attempt/hint/answer only. Historical summary fields `check=0` and `B_check=0` remain as inert compatibility columns. No checking event can occur. Request failures never magically count as received explanations. Independent/guided attempts and explaining to peers remain the only K increments. Grade and exam information never grant competence.

## Raw audit requirements

New `homework_feedback` table records source/release homework, student, grade, submitted route, assisted flag, credit vector, B/C before and after, shortfall before/after, signed satisfaction, and identical K before/after. Exactly N*H rows: each grade delivered once at h+1, including terminal feedback. Student snapshots log current shortfall/satisfaction and current B. Existing raw event/provenance/time/grade checks still apply. Tests must verify universal delivery, no within-homework grade leak, no checking, no time/K cost, reinforcement of successful copied answers, poor-grade incentives only for feasible answer requests, recovery on good grades, and unchanged historical source locks.

## E11 design, fixed before its outcomes

Exploratory correction; alpha and reaction constants are assumptions, not fitted student data. Seed 924201, 100 paired independent classrooms, N=30, H=20, T=12. All variants use universal delayed homework grades and no checking. Conditions: reference (no shortfall incentive), proposed response .4, weaker .2, stronger .8, no action-benefit reinforcement, no answer requests, no explanation requests, assisted-confidence attribution 0 and .8, reference/response at H40, reference/response on ER (13 conditions, 1,300 runs). Default grade target .75 is provisional; the experiment does not estimate the best target or claim population generality. No tuning to maximize knowledge separation.

Primary comparison: response .4 versus zero. Report all conditions, final knowledge, unaided exam, grade, copied submissions, completed attempts, explanation requests and actual receipts, self-assessment error, grade shortfall, satisfaction, and within-class K P90-P10. Use E10's exact event-gain decomposition and fixed early-attempt groups, but derive labels from E11's own no-response reference for each graph family. Their differences are observational, not causal behavior effects.

Audit and summarize positive B_answer updates after above-target copied grades; negative B_answer updates after below-target copied grades; and shortfall-induced changes in recorded answer-request choice scores. These local reactions are encoded rules, NOT emergent discoveries. Derive transitions from returned above/below-target grades to the next homework's attempts, questions and copying, separating associations from paired intervention effects. Report counts and mark empty cells unavailable.

Uncertainty: 2,000 paired whole-classroom bootstrap resamples, seed 924202, pointwise 95% intervals. Freeze sources/tests/design/analysis before runs; preserve all raw logs and hashes; independently rerun both reference and response conditions. A24 is a user-specified phenomenological hypothesis about grade-seeking, not a universal empirical law: some actual students may respond differently to failure.
