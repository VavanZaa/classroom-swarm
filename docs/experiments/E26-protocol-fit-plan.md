# E26: protocol-corrected bounded fitting

Declared 2026-10-10 before E26 outcomes. This follow-up preserves the complete E25 training/selection search and stops E25 before its untouched fresh pool. E25 inadvertently inherited a teacher reward contract of strength 1 in studies without teacher pay incentives. E25 also allowed an admissible candidate with no rewarded helper sessions. These are additional configuration/acceptance problems, not evidence that human mechanisms are wrong. Its selected settings must not be promoted as a study reproduction. All rejected candidates and raw tables remain under `runs/E25-plausible-fit-r1`.

E26 retains the meanings, ten bounds, physical-learning/knowledge/quantity controls, primary targets, loss tolerances and statistical definitions of [E25](E25-plausible-fit-plan.md). The numerical bounds are exploratory admissible assumptions, not published parameter estimates. E26 changes these declared protocol/acceptance features:

- In every comparison without teacher performance pay, set `extensions.teacher_work.contract.strength=0`, including STAR, tracking, AI and peer studies. Explicit teacher reward arms retain 0 versus 1; these strengths cannot be tuned. A study asking about class size must not accidentally reward its teachers for exam performance.
- STAR permits the existing individualized explanation as well as guidance under the same total teacher budget. Explanation already has activity/content/attention/effort physics; guidance only changes preference for study. A class-size setup restricted to preference nudging is an incomplete representation of individualized instructional capacity. This is a configured existing interaction, not a direct class-size bonus or new tool. The contrast between the old and corrected protocol is bundled (reward removal plus explanation availability), and is labeled as such.
- The class-size admissibility check requires actual guidance or explanation. The peer-incentive check requires at least 0.01 actual rewarded helper sessions per student per block, in addition to score loss. A model cannot count an inactive reward mechanism as a compatible explanation of the field's helping intervention. Teacher test coaching, productive dose and baseline participation screens are retained.
- Initialization includes the reference, three declared feasibility probes within the same bounds (higher intrinsic/gain beliefs and lower costs, plus helper cost/value variants), and four seeded random vectors. Two generations then evolve all eight candidates using the same bounded `rand/1/bin` algorithm. All probe values are saved before their outcomes. These probes test a hypothesis; endpoint selection does not establish true human values.

E26 uses distinct cohorts: two training IDs 54000–54001, four selection IDs 55000–55003, and sixteen untouched fresh IDs 56000–56015. Selection is still the best three feasible training candidates plus reference, then smallest feasible independent-selection loss. If no selection candidate is feasible, label failure and retain the fallback reference only as a diagnostic. E26 is a limited search, not proof of global optimality or impossibility.

Fresh profiles are frozen A33 default (`legacy`), A34 with corrected study protocols at default parameters (`protocol`), and selected A34 protocol parameters (`selected`). The eight primary/secondary setups are retained. STAR additionally runs A34 policy correction with the original contract/actions (`policy_only`) to separate the effect of the policy repair from the subsequent protocol changes. Report all previous-study reversals, all fifteen primary targets, pointwise and simultaneous intervals, and activity evidence. Secondary single/repeated peer-lab probes and composition remain incomplete protocol comparisons.

No new simulation mechanism is added in this follow-up: the existing explanation, helper-contract and test-preparation mechanisms are configured and checked. Failure of this finite search calls for a pathway diagnosis. A field mechanism that is absent (such as elective after-class teacher coaching or richer laboratory task/teachback protocol) must be documented; a new interaction cannot be justified merely by a missed sign. The user's parameter-plausibility requirement takes precedence over perfect fit.

Primary references are linked in E25. The [teacher incentive trial](https://www.aeaweb.org/articles?id=10.1257/app.2.3.205) is an explicitly paid intervention; [STAR](https://www.nber.org/papers/w6051) randomizes class sizes. Importing a generic paid-teacher contract into both protocols is not justified by those interventions. The [peer incentive study](https://www.aeaweb.org/content/file?id=15848) explicitly provides an incentive for high achievers to help their assigned peers. Teacher coaching here occurs during reserved class time; the trial's additional preparation sessions outside normal hours remain a protocol gap even if the score directions agree.

All E25/A34 and historical source locks are verified before E26 locking. E26 saves full raw tables, live and reloaded audits, declarations, rejected candidates and independent selection/fresh records, using E25's lossless gzipped JSON format. Independent causal-input reconstruction may be performed afterward as a read-only audit. Outcome-driven engine changes would need another named model and run; no frozen file may be edited to improve signs.
